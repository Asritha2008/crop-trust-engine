All scalers, covariance matrices, and calibration maps are fitted exclusively on these training rows.
- **Validation set**: 330 [source: backend/models/arena_metrics.json > class_wise_performance.accuracy_total] rows (exactly 15 [source: backend/models/arena_metrics.json > class_wise_performance.per_crop_metrics.apple.support] rows per crop across all 22 [source: backend/models/arena_metrics.json > benchmark_metadata.classes_count] classes). Reserved exclusively for post-calibration model tuning, class-wise error analysis, and stability auditing.
- **Test set**: Withheld and unopened throughout all model development and hyperparameter tuning (TODO: final test set evaluation remains quarantined). Following strict project governance, test set split files were never loaded.

### 1.5 Exploratory Findings and Dataset Separability

Statistical exploration of the training partition revealed:
1. **Univariate Overlap vs. Multivariate Separability**: Individual feature ranges overlap heavily across many crop classes (for example, nitrogen, phosphorus, and potassium distributions overlap across multiple legume and grain classes). However, within the full 7 [source: backend/models/arena_metrics.json > benchmark_metadata.features_count] dimensional feature space, distinct crops form isolated multi-modal clusters [source: notebooks/01b_eda_analysis.py > line 305]. This geometric separation explains why standard supervised classifiers achieve ~99% accuracy on clean data, while highlighting the critical need for a joint multivariate out-of-distribution (OOD) detector to identify anomalous voids between clusters [source: notebooks/01b_eda_analysis.py > line 305].
2. **Feature Correlation**: Phosphorus (P) and Potassium (K) exhibit a strong positive linear correlation (Pearson $r = 0.74$ [source: notebooks/01b_eda_analysis.py > line 142]), whereas other feature pairs exhibit minimal linear collinearity.
3. **Empty Bivariate Regions**: Several 2D parameter spaces contain wide empty regions where both features are individually frequent but never co-occur in the training data (e.g., High N with Extreme K, High N with Low Humidity, and Extreme P with Low K) [source: notebooks/01b_eda_analysis.py > line 191]. These regions illustrate impossible combinations that easily bypass naive 1D range checks but are correctly intercepted by multivariate density models.

### 2.4 Model Selection and Amendment Rationale

The shipped champion model is **Extra Trees (Isotonic)** [source: backend/models/arena_metrics.json > champion_model].

Crucially, the choice of the champion model comes from the validation probability calibration experiment (E4) evaluated on the 330 [source: backend/models/arena_metrics.json > class_wise_performance.accuracy_total] held-out validation rows under clean and simulated physical noise conditions, not from the E2 training cross-validation table (which served strictly as an architectural benchmark comparison across algorithms).

The model selection followed an explicit technical audit and governance amendment [source: backend/models/arena_metrics.json > selection_rationale; docs/decisions.md > 2026-11-08 "Final model = lowest post-calibration log-loss" & "Amendment: final model = Extra Trees"]:
- **Original Decision Rule**: "Final model = lowest post-calibration log-loss on VAL; ties broken by ECE, then noisy accuracy" [source: docs/decisions.md > 2026-11-08 "Final model = lowest post-calibration log-loss"]. Under this clean validation rule, Gaussian Naive Bayes (isotonic) would have been chosen over Extra Trees (isotonic) based strictly on clean log-loss (0.0116 vs 0.0147) [source: docs/decisions.md > 2026-11-08 "Amendment: final model = Extra Trees"].
- **Governed Amendment**: "Rule changed after seeing results. Over 5 noise seeds (42-46, noise.py 1 sigma, same 330 val rows) ET isotonic vs GNB isotonic: noisy log-loss lower in 5/5 seeds (mean diff -0.49), noisy ECE lower in 5/5, noisy accuracy higher in 4/5. ET isotonic has the lowest mean noisy ECE of the nine variants (0.027) but not the lowest noisy log-loss (ET sigmoid 0.246 vs ET isotonic 0.424 +/- 0.159); ET sigmoid is far worse calibrated on clean data (ECE 0.082 vs 0.008). Caveats: seeds are noise draws on the same val rows, not independent data" [source: backend/models/arena_metrics.json > selection_rationale; docs/decisions.md > 2026-11-08 "Amendment: final model = Extra Trees"].

Extra Trees with isotonic calibration was therefore selected and serialized to `backend/models/crop_pipeline_calibrated.joblib` as the production champion pipeline.
